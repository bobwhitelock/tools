# Tools

A collection of small, self-contained browser tools.

## Adding a new tool

- Write each tool as a **single pure HTML/CSS/JS file** — no build step, no external frameworks.
- **Add it to `index.html`** so it appears in the tools list.
- Before starting, **check existing tools for inspiration** — if one has a similar function, use it as a reference for patterns, style, and conventions.
